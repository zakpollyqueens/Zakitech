Bulk payment links

Import a CSV or Excel workbook containing multiple upgrade requests for Molan Business and Molan Chat. Review every row before sending the batch to the secure payment backend.

1. Upload your sheet

Supported formats: .csv, .xlsx, .xls. Use the first worksheet for Excel files. Each row should contain one payment request.

2. Required columns

Use these column names in the first row:

  • product — Molan Business or Molan Chat
  • customer_name, country
  • plan, currency, amount
  • reference — unique for every request

Optional: customer_email, customer_phone, period_months, description, expires_on.

Amounts are never converted automatically. Confirm the country, currency and approved plan price before generating links.

Payment security & live connection

Live link creation must run through a protected backend function using the correct GlobalPay/Globpay merchant API and server-side credentials. This page never stores API secrets and never marks an upgrade paid based only on a redirect.

The backend must verify provider status or signed webhooks before activating Molan Business or Molan Chat upgrades. Until the provider and merchant account are confirmed and configured, this page can validate and export batches but cannot create genuine live payment links.
