# ZakiTech

A Zakmolanitech Solutions official app and company workspace.

## Current starter

The first UI milestone includes:
- A branded welcome screen with a custom animated robot mascot.
- A three-second welcome sequence that transitions into the sign-in form.
- A responsive cyan-blue and deep-navy sign-in design.
- Username/email and password fields, show/hide password, and a keep-me-signed-in checkbox.
- An optional short welcome tune, activated only when the visitor taps the sound control.
- Initial UI responses for password recovery and account creation.

## Important authentication status

The sign-in screen is currently a frontend prototype. It does **not** authenticate users, create accounts, or store/send entered credentials. The next implementation step is to connect a real authentication provider, configure account registration and password recovery, and enforce server-side authorization before enabling sign-in.

## Run locally

Open `index.html` in a modern browser, or serve the repository root with a static web server. No build step is required for this UI milestone.

## Project direction

ZakiTech is a separate company-management application. ZakiChat is one of the products that will eventually be represented in the ZakiTech Product Hub; it is not the ZakiTech codebase.
